# Gestor Cron & Comandos

App GUI para cualquier distro Linux que permite crear tareas cron/systemd y comandos de shell personalizados de forma gráfica.

**Estado:** solo planificación, sin código todavía. Ver [`docs/ARQUITECTURA.md`](docs/ARQUITECTURA.md) para el blueprint completo (stack, modelo de datos, backends, diseño de GUI, diseño de `install.sh` y roadmap de implementación).
